# One-page portrait reflection

Use the requested voice and page format. Ask for missing shoot facts early while editing continues: intended mood; how the model was directed; location and light choices; prior feedback actually applied. Never invent those facts from the image. EXIF can establish recorded settings but not the photographer's reason for choosing them.

Draft about 350-450 words when no different length is specified, then render to confirm one actual page. Organize connected paragraphs around:

1. **Intent and execution:** intended mood and how framing, pose, gaze, and expression support it.
2. **Photo-taking process:** actual location, lighting, model direction, foreground/background decisions, and known settings when relevant.
3. **Editing process:** actual sequence from global tone/color and crop through cleanup, local tone work, eyes, and sharpening. Explain why each meaningful change supports the portrait. Name the editor used and acknowledge automated assistance when it performed the work; do not claim manual student edits.
4. **Growth:** specific feedback applied, an honest assessment of the result, and a concrete improvement for the next shoot.

Disclose a missing required RAW source and other material workflow gaps. Do not bury them in a claim that every requirement was met. Exclude temporary scripts, browser troubleshooting, and unrelated implementation details from the reflection.

For PDF or Word output, use available document tools and applicable artifact skills. Reopen the final file, check page count, render and inspect the page, and ensure no clipped text, placeholders, or layout overflow. Do not present an unrendered one-page claim based only on word count. The reflection describes the actual delivered image, so revise it if the editing changes.
