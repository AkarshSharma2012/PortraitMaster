# Verification and rubric audit

Use evidence from the actual saved deliverables. A successful save or a count of named layers alone does not prove edit quality or nondestructiveness.

## Image review

- At fit-to-screen: assess face emphasis, crop, gaze space, mood, believable color, tonal balance, and background distractions.
- At 100%: inspect the actual eyes, skin pores, hair boundaries, cleanup patches, repeated clone patterns, halos, mask seams, and clipped detail. Zooming a soft image does not establish sharp in-camera focus.
- Flip horizontally for a temporary inspection and compare the edited image with the untouched source. Restore the intended orientation for export.
- Toggle each relevant edit or group. Check that it changes the intended area and does not distort identity. Distinguish a screenshot review from an actual on/off comparison when only one is available.

## Saved file checks

- Reopen the exact final PSD and check dimensions, layer types, masks, opacities, visible state, original embedding, and editable filters/adjustments. Test meaningful sample toggles and verify source availability.
- Inspect the saved merged preview. Some PSD libraries retain a previous composite or cannot render a particular Smart Filter; use the editor to force recomposition and resave when needed.
- Reopen the exported JPEG, check dimensions/orientation, embedded sRGB profile, and visual agreement with the PSD. A renamed extension alone is not a format conversion.
- Confirm exact filenames, destination paths, and file sizes. After moving/copying, use matching hashes when practical. Preserve unrelated files; do not overwrite a different deliverable silently.
- PSD layers persist edits and settings; they are not the same as a complete chronological Photoshop History panel. Do not promise persistent undo history unless that feature was explicitly configured and verified.

## Rubric mapping

Assess each supplied criterion against its actual wording. For the seven-category portrait rubric, use this mapping:

| Criterion | Evidence | Editing limit |
| --- | --- | --- |
| Composition | Intentional framing, balanced placement, headroom, gaze space, joint crops | Cropping cannot restore absent body parts or prove original intent |
| Model position and posing | Shoulder/head/hand angles, natural expression, direction reported by photographer | Editing cannot prove model direction or fix an in-camera criterion retroactively |
| Background | Subject separation, restrained colors, cleaned distractions | Repairs must remain natural and editable |
| In-camera focus and exposure | Original eyes at 100%, original face highlight/shadow detail | Sharpening is not proof of tack-sharp capture; lost data may be unrecoverable |
| RAW processing and color | Real RAW source when required, believable skin, deliberate tone, refined crop | JPEG input cannot satisfy a RAW-original requirement |
| Retouching and finishing | Natural texture, selective cleanup, subtle eyes, masked sharpening, genuine layers | Layer count alone does not earn the top band |
| Intent and growth | User's real intent, specific prior feedback, demonstrated changes | Do not invent earlier rounds or feedback |

Use `complete`, `not applicable`, `unmet`, or `unverified` for workflow items, with short evidence and the remaining action. Optional frequency separation, whitening when teeth are not visible, and unnecessary noise reduction can be not applicable. Required source formats cannot be marked not applicable merely because they are missing. Never guarantee an A, 4.0, or teacher score.

## External handoff

Keep editing, file delivery, upload, and final submission as separate verified states. Confirm the intended account and destination. Attachment size limits vary; use the service's actual response and an authorized cloud link when needed. Do not make files public just to bypass a transfer limit. If a picker, authentication requirement, or tool policy prevents completion, preserve the files and give a precise handoff rather than claiming delivery.
